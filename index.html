Philosophy

我们相信的三件事

Three convictions that shape every pixel of GitPulse.

数据即脉搏

Data is the pulse

每 6 小时捕获一次，如同心电图般记录开源世界的每一次心跳。不是静态的排行榜，而是活着的信号。

趋势即方向

Trends are direction

从 topics 关键词云中，你能看到技术思潮的涌动。不是事后回顾，而是此刻正在发生的事。

极简即尊重

Restraint is respect

Apple 级的设计语言，因为好的数据值得好的容器。每一个像素都服务于信息，而不是装饰。

Features

每一个特性，都有理由存在

Zero dependencies. Pure HTML / CSS / Vanilla JS.

Apple-grade 暗色设计

受 Apple 产品页启发，极致克制的视觉语言。深度通过色彩层级表达，而非阴影。

纯 HTML/CSS 图表

语言分布条、Stars 排行、关键词云 — 零依赖，全端自适应，加载即呈现。

滚动渐现动画

IntersectionObserver 驱动，每个元素在进入视口时优雅浮入。流畅，不突兀。

数字跳动计数器

关键指标从 0 动态增长，数据有生命力。让数字说话，而不是静态文本。

全响应式

桌面、平板、手机，完美适配。在任何设备上都能获得一致的体验。

每 6 小时自动更新

GitHub Actions 自动抓取，数据永不过时。cron: 0 0,6,12,18 * * *

Topics 关键词云

从仓库标签中提取技术趋势，一目了然。热点词用颜色和大小区分权重。

零框架，零依赖

纯 HTML / CSS / Vanilla JS，无框架、无库、无构建步骤。直接部署 GitHub Pages。
