Philosophy

我们相信的三件事

Three convictions that shape every pixel of GitPulse.

01

数据即脉搏

Data is the pulse

每 6 小时捕获一次，如同心电图般记录开源世界的每一次心跳。不是静态的排行榜，而是活着的信号。

02

趋势即方向

Trends are direction

从 topics 关键词云中，你能看到技术思潮的涌动。不是事后回顾，而是此刻正在发生的事。

03

极简即尊重

Restraint is respect

Apple 级的设计语言，因为好的数据值得好的容器。每一个像素都服务于信息，而不是装饰。

Features

每一个特性，都有理由存在

Zero dependencies. Pure HTML / CSS / Vanilla JS.

01

官方 Trending 语义

直接抓取 github.com/trending，按时间窗内 stars 增量排序，而非新建仓库凑数。

02

中英双语切换

全站中文/English 一键切换，浏览器语言自动检测，偏好持久化。

03

实时搜索筛选

仓库名和描述即时过滤，按语言精确筛选，200ms 防抖零延迟。

04

内联详情面板

点击仓库卡片展开完整信息：创建日期、Last Push、Forks、Issues。

05

增量徽章

显示本期 stars 增长（今日/本周/本月），直接看到什么在涨。

06

每 6 小时自动更新

GitHub Actions 自动抓取，数据永不过时。cron: 0 0,6,12,18 * * *

07

ECG 脉搏动画

Canvas 绘制的心电图实时动画，视口内才绘制，性能友好。

08

零框架，零依赖

纯 HTML / CSS / Vanilla JS，无框架、无库、无构建步骤。直接部署。

追踪脉搏，而非噪音。

Track the pulse, not the noise.
